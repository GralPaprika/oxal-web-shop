## 🎯 Mobile SEO Checklist

### Performance Metrics
- [ ] **LCP** (Largest Contentful Paint): < 2.5s on 4G
- [ ] **FID** (First Input Delay): < 100ms
- [ ] **CLS** (Cumulative Layout Shift): < 0.1
- [ ] **Page Load Time**: < 3 seconds on mobile
- [ ] **First Paint**: < 1.5 seconds

### Usability
- [ ] Text is readable without zooming
- [ ] Buttons/links are 48px+ tall (touch target)

- [ ] Forms are easy to use on mobile

## 📊 Mobile Testing Tools

### Test Your Site:
1. **Google Mobile-Friendly Test**
   - https://search.google.com/test/mobile-friendly
   - Shows issues & recommendations

2. **Google PageSpeed Insights**
   - https://pagespeed.web.dev
   - Mobile performance score
   - Core Web Vitals status

3. **Lighthouse (in Chrome DevTools)**
   - F12 → Lighthouse tab
   - Full audit with recommendations

4. **Mobile Simulation**
   - Chrome DevTools (F12 → Toggle device toolbar)
   - Test on iPhone, Android, tablets

### What to Look For:
- ✅ Green scores for mobile performance
- ✅ All Core Web Vitals "Good"
- ✅ No layout shift issues
- ✅ Fast loading times
- ✅ Accessible on all screen sizes

## 🔍 Mobile SEO Best Practices

### 1. **Mobile-First Content**
- Keep most important content above the fold
- Short paragraphs (mobile readers scroll less)
- Large, readable fonts (minimum 14px for body text)
- White space for readability

### 2. **Touch-Friendly Design**
- Buttons: 48×48px minimum (done ✓)
- Links: 44×44px minimum spacing
- No hover-only content
- Easy to tap, hard to mis-tap

### 3. **Fast Loading**
- Images optimized (done ✓)
- Minimize CSS/JS
- Lazy load below-the-fold content
- Cache aggressively (done ✓)

### 4. **Mobile Features**
- Click-to-call links (done ✓)
- Location links with maps (done ✓)
- WhatsApp integration (optional)
- One-tap social sharing

### 5. **Mobile Indexing**
- Same content on mobile as desktop
- No mobile-specific hidden content
- Robots.txt allows mobile crawling (done ✓)
- Schema markup visible on mobile
